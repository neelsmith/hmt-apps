# hmt-apps


> *Stand-alone web apps for exploring data from the Homer Multitext project.*


## On the web

- all apps are installed on the repository github pages site: [use them there](https://neelsmith.github.io/hmt-apps/) 


## Run locally

- internet access required
- all HTML files in the [`dist`](https://github.com/neelsmith/hmt-apps/tree/main/dist) directory can be saved to a local file and run by opening them in a browser
